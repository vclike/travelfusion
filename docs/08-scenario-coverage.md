# 场景覆盖矩阵（行程规划全生命周期 · 2026-09-29）

> 图例：✅ 免费　💰 付费　🌐 网页兜底（search-fusion/浏览器，非结构化）　❌ 无数据源　🔧 插件自建（纯计算，零外部依赖）
> 本矩阵是**功能范围合同**：开发验收时逐行核对。

## 1. 灵感与决策期（出发前数月）

| 场景 | 方案 | 成本 |
|---|---|---|
| "我这预算能去哪"（低价目的地发现·国际） | Travelpayouts `/v2/prices/nearest` + popular directions | ✅ |
| 国内低价航线发现 | 飞常准 `getAirportLowPriceRoutes` | 💰（免费无源） |

| 签证/入境要求 | 飞常准 `getAirportStrategy`（入境卡）；或 🌐 | 💰/🌐 |
| 目的地安全提示/外交部提醒 | 🌐 | 🌐 |

## 9. 结构性缺口汇总（免费方案做不到，明确不承诺）

| 缺口 | 原因 | 兜底 |

| 火车正点率 | 12306 无此字段，无替代源 | 🌐 |
| 境外公共交通/POI | 高德仅境内 | 🌐 |
| 实时充电桩状态 | 所有开放 API 均无 | 出发前 App 核验 |
| 行李额/超重费 | 无结构化源 | 🌐 航司官网 |
